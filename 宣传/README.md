# miku camera · 今天，也和 Miku 一起。

网页与视频分别实现，参考相邻 MDmeow 项目的奶油白、初音绿、实机截图与简短叙事节奏。使用项目提供的截图和本机表情包，没有修改原素材或 Android 应用。

## 成品

- **当前视频版本**：`website-film-fast/miku-camera-50s-1080p.mp4`，50 秒，1920×1080，中文配音与字幕，使用指定歌曲作 BGM。10 段完整故事线、13 张截图，精简功能文案与快速横向切页；详细重建说明见 `website-film-fast/README.md`。下方根目录的视频文件为早期版本。
- `../docs/index.html`：响应式横向翻页网页，主要内容居中，截图与功能描述左右交替。点击内容区域时向左切换下一页，支持滚轮、方向键和触屏左右滑动；最后一页停止翻页，使用下方「返回首页」按钮回到开头，下载与项目链接独立响应；移动端在单页内上下排版，不进行纵向翻页。截图按原始比例显示，无白色外框或留白，每张原始截图仅展示一次；顶部与内容统一限制在 1280px 居中区域内；顶部仅保留品牌与下载按钮，底部无控制栏，内容区仅最后一页保留两个操作按钮。网页只有截图，没有视频、视频链接或嵌入播放器。
- `miku-camera-promo.mp4`：独立成片，约 64.43 秒，1920 × 1080，30 fps，H.264 + AAC，中文合成女声、原创轻柔配乐、画面内中文字幕。
- `cover.jpg`：视频封面。
- `film.html` / `film.js`：固定画幅的视频动画源文件与独立预览，不依赖网页的滚动或布局。
- `captions-reference.srt`：后期参考字幕。成片已有一层画面内字幕，无需再叠加。
- `timing.json`：按实际旁白长度编排的时间轴。
- `asset-sources.json`：截图和表情包的原文件映射。
- `qa/`：网页多尺寸截图、8 幕抽帧、检查报告（本地文件，不纳入版本控制）。

## 修改和重建

网页内容在 `docs/index.html`，样式在 `docs/site.css`。视频文案与构图在 `film.js`，旁白脚本与原创配乐在 `make_audio.py`。旁白为 `zh-CN-XiaoxiaoNeural` 合成声音，未模仿人物；配乐由程序合成，不含外部音乐采样。

准备素材（需要原始截图、表情包目录和 Pillow）：

```powershell
python 宣传/prepare_assets.py
```

准备配音依赖和生成音频（Python 还需 numpy、scipy、soundfile）：

```powershell
python -m pip install --target 宣传/.deps edge-tts==7.3.1
python 宣传/make_audio.py
```

配音生成会将脚本文本发送到语音服务；已有有效的分句配音会缓存复用。修改某句后，删除对应 `audio/voice-幕号-句号.mp3` 再重建。

导出成片，修改旁白后使用 `timing.json` 中的新时长：

```powershell
node 宣传/render.mjs --duration 64.43333333333334 --fps 30 --audio audio/mix.wav --out miku-camera-promo.mp4 --preset fast
node 宣传/render.mjs --snapshot 2 --snapshot-out cover.jpg
```

渲染器沿用并调整了 MDmeow 的本地逐帧导出工具，读取本机 Playwright、Chromium 及相邻 MDmeow 的 FFmpeg；可通过 `PLAYWRIGHT_DIR`、`CHROME_PATH`、`FFMPEG_PATH` 指定位置。只启动独立隐藏浏览器来渲染本地文件，不操作用户标签页。视频素材由 `prepare_assets.py` 同步至 `宣传/assets/`，不依赖网站运行。

运行预览服务后，执行 `node 宣传/check-web.mjs` 检查网页的横向翻页、多尺寸布局、滚轮与键盘、触屏滑动、点击翻页、末页停止与主动返回首页、下载链接互不干扰及无底部控制栏。此次网页修订未重新生成视频，视频仍为之前版本。

执行 `python 宣传/validate_video.py` 可独立检查 MP4 的分辨率、帧率、音轨、时长、完整解码与编码后抽帧。本次成片验证通过：1933 帧，64.43 秒，1920 × 1080 / 30 fps，H.264 + AAC，单层画面内字幕。


## 网页故事线（当前版本）

沿用现有居中布局，13 张原始截图按文件时间顺序展示，每张只出现一次，不再以同图局部放大或下载页复用造成重复。

1. 桌面图标：从桌面打开 Miku Camera。
2. 相机取景：Miku 水印、时间地点与拍摄控制。
3. 水印列表与编辑：选择、新建、上传 PNG、编辑显示选项（2 张）。
4. API 配置：多套配置切换与新增协议选择（2 张）。
5. 相机设置：默认启动、默认提示词、参考图及关于应用。
6. AI 选图：原图与参考图、提示词、形象、服装、分辨率。
7. 桌面悬浮窗：后台任务列表、提交与生成状态。
8. 公式服结果：二次元与真人写实（2 张）。
9. 非公式服结果：两种形象、原图对比与保存（2 张）。
10. 下载：使用应用图标收尾，不重复截图。

`web-story.json` 逐张记录来源、页面与说明。`build_web.py` 生成网页并检查 13 张截图无遗漏、无重复且顺序与源文件一致。运行 `python 宣传/prepare_assets.py --web-only` 仅准备网页素材，不更新视频素材；再运行 `python 宣传/build_web.py`。视频保持此前版本，本次没有重新制作。
