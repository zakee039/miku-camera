MIKU CAMERA / ANDROID

从桌面，
打开 Miku Camera

水印拍摄与 AI 创作，从桌面直接开启。

  • 普通模式打开即可拍摄 Miku 合影
  • AI 模式把 Miku 融入实拍照片

01 / CAMERA

进入取景框，
直接预览水印

取景时预览水印，拍下看到的画面。

  • 实时预览Miku、时间与地点一起保留
  • 拍摄控制对焦、曝光、闪光灯

02 / WATERMARK

选择水印，
再调整它的样式

选择预设，或上传自己的 PNG 水印。

  • 自定义样式位置、旋转、描边自由调整
  • 独立排版按需显示时间与地点

03 / API CONFIGURATION

配置 AI 服务，
按需切换模型

保存多套 API 配置，切换服务与模型。

  • 多套配置保存、选择、继续编辑
  • 多协议OpenAI · Gemini · 兼容接口等

04 / CAMERA SETTINGS

设置默认模式，
保存创作偏好

提前设好启动模式、提示词和参考图。

  • 启动偏好普通水印 / AI 模式
  • 创作预设默认提示词与形象参考图

05 / AI CREATION

选好原图，
确认这一张的创作

选好照片，确认提示词与生成参数。

  • 形象与服装二次元 / 真人 · 公式服 / 非公式服
  • 输出分辨率1K / 2K / 4K

AI 模式需使用你配置的 API 服务。

06 / BACKGROUND TASKS

回到桌面，
也能查看生成进度

回到桌面，悬浮窗继续显示任务进度。

  • 后台生成不必一直停留在应用内
  • 多项任务同时查看状态与生成参数

07 / CLASSIC OUTFIT

同一处风景，
两种形象的结果

同一处风景，查看两种形象的生成结果。

  • 二次元动漫形象融入实拍风景
  • 真人写实写实风格呈现 Miku

应用内实际生成示例，效果随模型与输入变化。

08 / REFERENCE OUTFIT & SAVE

再看参考造型，
对比并保存结果

换上参考造型，按住图片对比原图。

  • 继续修改调整提示词，或重新拍摄
  • 保存到相册AI 图、原图，或两张都保留

应用内实际生成示例，效果随模型与输入变化。
