# 水印相机（Android Kotlin MVP）

这是一个原生 Android / Kotlin 的水印相机 MVP，打开应用直接进入拍照模式。

## 已实现的功能

- CameraX 前后镜头切换。
- 闪光灯关闭 / 开启 / 自动三态切换（设备不支持时安全回退）。
- 通过系统文件选择器导入带透明通道的 PNG，并持久化 URI 权限。
- 编辑模式下 PNG 默认居中、宽度为取景框的 50%，支持单指拖动和双指缩放/旋转。
- 时间、地点两个文本水印，可独立开关、拖动、缩放和旋转。
- PNG 描边半径可调（0～24 像素，预览中实时显示）。
- 水印配置以 JSON 保存到 SharedPreferences，选择水印时从底部列表加载。
- 拍照后在后台将水印合成到原图，再写入系统相册 `Pictures/水印相机`。
- 新建水印时自动隐藏闪光灯、镜头切换和拍照按钮，只显示取景框与编辑控制。

## 打开与运行

使用 Android Studio 打开本目录，等待 Gradle 同步后直接运行 `app`。第一次启动需要相机权限；开启地点水印时再申请定位权限。

项目使用 CameraX 的通用接口：`Preview` 提供取景、`ImageCapture` 拍照与闪光灯模式、`CameraSelector` 切换前后摄像头，因此不依赖某个厂商的相机 SDK。

## 后续可扩展

当前是单模块 MVP，适合先验证交互。生产版本建议继续补上：相册缩略图入口、拍照方向与前置镜像策略、用 Room 替代 SharedPreferences、对大尺寸照片做分辨率/内存保护，以及可配置的地点格式（地址、经纬度、海拔）。
